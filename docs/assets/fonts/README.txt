FONTS USED FOR THE PROVISIONAL QUBIT WEBSITE

Unbounded (headings) and Manrope (body) are locally served variable fonts.
They approximate the supplied Qubit direction; they are not asserted to be
the designer's original typefaces. No request to a third-party font service
is made by site visitors.

Original upstream files, unchanged:
https://github.com/google/fonts/tree/main/ofl/unbounded
https://github.com/google/fonts/tree/main/ofl/manrope

OFL license texts accompany both fonts. Exact download URLs and SHA-256 values
are recorded in sources.json. Prepared 2026-11-05.
